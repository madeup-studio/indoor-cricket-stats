# Indoor Cricket Stats

Scorecard photo → phone-first team stats and an AI coach, for indoor cricket
(or Action Cricket). The coach writes a letter after every game.

**Status: planning (2026-10-22).** Nothing runs yet. The design and the build
plan live in `docs/superpowers/`.

What it will be:

- Photograph the Spawtz scorecard at the arena and hand it to Claude Code from
  your phone; every ball is transcribed and reconciled against the card's totals.
- A small web app your team opens from a link: rankings, player pages, game
  pages, records and the coach's letter — big type, built for phones.
- Each team runs its own copy, free: a private GitHub repo + Cloudflare Pages
  + a Claude subscription. No accounts to build, no data on anyone else's server.
- Open source (MIT). The first open-source release of MaDe-uP Studios.
