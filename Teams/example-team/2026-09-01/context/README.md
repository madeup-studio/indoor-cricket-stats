# Season context (supplemental, non-scorecard info)

Anything that is NOT a scorecard but should inform the reports and the AI Coach
letter: league table screenshots transcribed to text, fixtures, comments about a
game, guest players, banter material.

- One file per upload, named `YYYY-MM-DD-<topic>.md` (date = when the info was true).
- Keep data faithful to the source (transcribe tables as markdown tables).
- Context only: never parsed by the stats pipeline, never overrides scorecards.
